# Brassica_TE_Family
* scripts for analysis of transposons in Brassica oleracea and Brassica rapa
* This repository contains the scripts to analyze Brassica transposons, and visualization for each figures in the draft "Transposable elements drive evolution and perturb gene expression in Brassica"
* Paper Link: 
  * [Transposable elements drive evolution and perturb gene expression in Brassica rapa and B. oleracea - PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12401559/)
  * [Transposable elements drive evolution and perturb gene expression in Brassica rapa and B. oleracea - Zheng - 2025 - The Plant Journal - Wiley Online Library](https://onlinelibrary.wiley.com/doi/10.1111/tpj.70452)
  * https://doi.org/10.1111/tpj.70452


# Requirement
* data should be downloaded from figshare: https://doi.org/10.6084/m9.figshare.28151594.v1
